# Comunica-escala
Software de escalas médica que atua e conversa com app Comunica+

## ⚠️ Aviso Importante para Desenvolvedores

Os trabalhos de desenvolvimento deste software **devem ser realizados com acompanhamento do projeto Comunica+**, devido ao objetivo e planejamento original de serem aplicativos que conversam entre si.

Qualquer alteração, nova funcionalidade ou correção deve ser avaliada em conjunto com o projeto Comunica+, garantindo a compatibilidade e integração entre os dois sistemas.
